###OBJETIVOS GENERALES
# De las MIPM a valores - PANEL

Proyecto para calcular valores trabajo utilizando datos de tablas de insumo-producto mundiales para más de 40 países, por el periodo de 1995 al 2014.

También se incluirán estimaciones sobre:

- Intercambio desigual

- Tasas de explotación;

- Tasas de beneficio;

- Profit rates;

- diferente aproximación a los valores - precios directos, precios sraffianos

A hacer disponible por año, periodo, región, país y sector.
