# De las MIPM a valores - PANEL

Proyecto para calcular valores trabajo utilizando datos de tablas de insumo-producto mundiales para más de 40 países, por el periodo de 1995 al 2014.

También se incluirán estimaciones sobre:

- Intercambio desigual

- Tasas de explotación;

- Tasas de beneficio;

- Profit rates;

- diferente aproximación a los valores - precios directos, precios sraffianos

A hacer disponible por año, periodo, región, país y sector.

### Pasos del proyecto:


#### 1) Definir metodología básica


1.1) Investigación sobre datos y metodologías disponibles

1.2) Acordar una metodología estándar para las primeras estimaciones preliminares


#### 2) Recopilar información

1.1) Definición de fuentes de datos

1.2) Descargar / Importar los datos elegidos -> Script XXXX.R

#### 3) Presentar y hacer que los resultados estén disponibles de forma personalizada


2.1) Definición de indicadores disponibles al público

2.2) Definición de las visualizaciones disponibles: región, país, sector, periodo, cruces
