# WIOD to values panel
Project to calculate labor values using data on world input output tables for more than 40 countries.
Also to be included estimates on:
- Unequal Exchange;
- Exploitation rates;
- Profit rates;
- different approximation to values - direct prices, sraffian prices

Available by region, country and sector from 1995 to 2014
