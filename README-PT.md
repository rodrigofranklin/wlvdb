# Das MIPM aos valores - Painel

Projeto para calcular valores-trabalho usando dados em tabelas de insumo-produto mundiais para mais de 40 países, de 1995 a 2014.

Também devem ser incluídas estimativas sobre:

- Troca desigual;

- taxas de exploração;

- taxas de lucro;

- aproximação diferente aos valores - preços diretos, preços sraffianos, preços de produção etc

A tornar disponível por região, país e setor e período

### Etapas do projeto:


#### 1) Definir metodologia básica

1.1) Pesquisa sobre dados e metodologias disponíveis


1.2) Concordar com uma metodologia padrão para as primeiras estimativas preliminares

#### 2) Coletar informações

1.1) Definição de fontes de dados

1.2) Download / importação dos dados escolhidos -> Script XXXX.R

#### 3) Apresentar e disponibilizar resultados em um formulário personalizado


2.1) Definição de indicadores disponíveis ao público


2.2) Definição das visualizações disponíveis - região, país, setor, cruzamentos, período

2.3) Construção do painel -> server.R & ui.R Scripts?
